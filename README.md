#### RJPM UI Components es una biblioteca de componentes de interfaz de usuario (UI) desarrollada por Ricardo J. Parra M. Esta colección está diseñada para facilitar la creación de aplicaciones web modernas y responsivas, proporcionando componentes reutilizables y personalizables.

## Características

- **Componentes Reutilizables**: Incluye una variedad de componentes como botones, tipografías, inputs y más, que pueden ser utilizados en diferentes proyectos.
- **Diseño Responsivo**: Todos los componentes están diseñados para adaptarse a diferentes tamaños de pantalla y dispositivos.
- **Fácil Integración**: Se puede integrar fácilmente en proyectos existentes con un mínimo esfuerzo.

## Instalación

Para instalar la biblioteca de componentes, sigue estos pasos:

1. **Clona el repositorio**:

   ```bash
   git clone https://github.com/ricardojparram/rjpm-ui-components.git
   ```

2. **Navega al directorio del proyecto**:

   ```bash
   cd rjpm-ui-components
   ```

3. **Instala las dependencias**:

   ```bash
   npm install
   ```

4. **Ejecuta la aplicación de demostración (opcional)**:
   ```bash
   npm run dev
   ```
